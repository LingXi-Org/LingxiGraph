## 数据类型

- `SkillMetadata(name, description)`：discovery catalog 的最小数据。
- `SkillSpec`：解析后的字段、Markdown body 和原始完整 `SKILL.md`。
- `SkillResource`：`skill_name`、相对路径、MIME、bytes 和 `size`。
- `SkillValidationIssue`：包含 `path`、稳定 `code` 与消息。

## Source 与 Registry

`SkillSource` 定义同步的 `discover()`、`load(name)`、`read_resource(name, path)` 协议。
`FilesystemSkillSource` 是标准本地实现，`SkillRegistry` 合并多个 source 并拒绝重名。

```python
from lingxigraph import FilesystemSkillSource, SkillRegistry, validate_skill

issues = validate_skill("skills/hello")
registry = SkillRegistry([FilesystemSkillSource("skills")])
metadata = registry.discover()
spec = registry.load("hello")
resource = registry.read_resource("hello", "references/greetings.md")
```

当 `create_agent(..., skills=registry)` 启用 Skills 时，会自动增加 `read_skill(skill_name)` 和
`read_skill_resource(skill_name, path)` 两个普通 Tool Calling schema。文本资源以 UTF-8 返回；
二进制资源以带 MIME、size 和 Base64 content 的 JSON 返回。
